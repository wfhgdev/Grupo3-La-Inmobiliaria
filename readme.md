## 📖 Descripción

**La Inmobiliaria** es una solución web diseñada para facilitar la conexión entre compradores, inquilinos y agentes inmobiliarios. Permite explorar un catálogo de propiedades con filtros avanzados, gestionar publicaciones y solicitar información o citas en tiempo real.

---

## ✨ Características Principales

- 🔍 **Búsqueda Avanzada y Filtros:** Filtrado por ubicación, precio, tipo de propiedad (casa, departamento, local), número de habitaciones, etc.
- 🏠 **Catálogo de Propiedades:** Galería de imágenes, descripción detallada, ubicación en mapa y características destacadas.
- 👤 **Gestión de Usuarios:** Registro e inicio de sesión para clientes y administradores/agentes.
- 📝 **Publicación de Inmuebles:** Formulario intuitivo para añadir nuevas propiedades a la plataforma.
- 📞 **Contacto Directo:** Formulario de consulta directo con el agente a cargo de la propiedad.
- 📱 **Diseño Responsive:** Adaptado a dispositivos móviles, tablets y escritorio.
